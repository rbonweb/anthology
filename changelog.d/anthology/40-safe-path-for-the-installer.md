- Fix: when your PATH held a relative or empty entry (`.`, `::`, a leading or trailing `:`, or a folder such as `bin`), the repository you opened could supply programs that the plugin's hooks and the `anthology` and `anthology-mem` commands ran: the hooks' `sh`, and the `curl`, `tar`, `shasum`, `date`, `readlink` or `dirname` used while finding and installing the binary. The hooks now start with `/bin/sh`, and these helpers run on PATH without those entries, keeping the absolute ones in order and falling back to the standard system folders when none is left. The anthology binary still gets your PATH unchanged. The sha256 check is unchanged.
