- Fix: ATL no longer prompts for a harmless read, and no longer makes auto mode refuse a call. With any deny, ask or `Read()` rule set, a line that merely contains `atl` or the legacy `rtk` (`grep -n x atl/src/main.rs`, `ls -la atl | head -60`) was not in the plain shape, so ATL's hook asked about it, and a hook ask beats `Bash(atl *)` in every mode. When `anthology perm classify` shows the line as typed read-only, every path it reads is under the project, and no ask or `Read()` rule applies, ATL now allows the rewrite, or leaves the line to Claude Code when it cannot rewrite it plainly. Deny rules are checked first and still win, and an ask rule still asks. In auto mode ATL no longer rewrites a command at all, so auto mode judges what the model wrote instead of refusing with "a hook changed this call's input after auto mode reviewed it". Other modes rewrite as before. This is ATL `1.2.1-anthology.7`; `bin/atl-hook` now tells ATL where the plugin's `bin/anthology` is (`ATL_PERM_CLASSIFY`) and which `PATH` you exported (`ATL_HOOK_USER_PATH`). An ATL installed without the plugin has no classifier and asks as before.
