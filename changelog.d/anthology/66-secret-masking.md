- Add: Bash output passes a secret mask before Claude reads it. A new mod, `hooks/mods/masking.ts`, hooks `session.append` (door `tool-result`) and replaces AWS access keys, GitHub tokens, API keys, Slack tokens, private keys and the value of a `password` or `api_key` setting with a marker such as `[masked by anthology: github-token]`, for the main session and for subagents, before the model reads the result and before it is written to the transcript. Lockfile hashes, git SHAs, integrity strings, CSS class names and code that only reads a secret stay as they were. A cheap text check runs first, so output with no likely match starts no process; the masker is the new `anthology guard mask` (binary 0.2.11 and later) and the mod fails open when the binary is missing or older. `ANTHOLOGY_SECRET_MASK=0` turns it off.
- Add: a Write, Edit, MultiEdit or NotebookEdit whose new text contains the mask marker `[masked by anthology:` is refused, with the message to write the real value from its source (an env file or `~/.config/<project>/<service>.env`) and never the marker. It applies to subagents too and fails open.
