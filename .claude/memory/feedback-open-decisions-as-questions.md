When there are open decisions, ask them as multiple-choice questions (AskUserQuestion), recommended option first and labeled "(Recommended)", with the trade-off in each description.

**Why:** The user asked for exactly this ("give me questions with your recommendations") after I listed open decisions in prose. They often voice-dictate and may change an answer mid-turn; the latest message wins.

**How to apply:** Batch up to 4 independent decisions per question set; make each question self-contained. Decisions that are mine to make go in the plan as stated calls they can correct, not as questions.
