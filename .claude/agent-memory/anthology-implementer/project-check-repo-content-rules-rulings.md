crates/anthology-scan/src/rules/{hidden,payload,exfil}.rs. Orchestrator hooks: hidden::raise_homoglyph_twins(paths, findings); exfil::raise_reached(findings, reached) lifts MEDIUM exfil findings whose why ends with RAISE_NOTE (theft shape capped by a test path, any MEDIUM chat or ngrok webhook) to HIGH and swaps the note for RAISED_NOTE (Finding has no spare field, and repo text never reaches why); a comment, a docker bind or mount spec or a dump with no send near is never lifted. payload::raise_reached(f, out) and hidden::raise_reached(f, out) take the FileCtx of a reached file and push the findings the generated-folder cap (blob, decode-exec HIGH) or the test-path cap (bidi HIGH) held back; scan.rs merges one finding per rule and path, higher severity wins. Homoglyph test is per word. payload.decode-exec: within 10 lines HIGH, farther apart in one file MEDIUM. exfil.cred-path is HIGH only for a path in code, not a bind spec, read by a real read call within 3 lines or a redirection, with a send within 10 lines; test paths cap it at MEDIUM. exfil.env-dump: a serializer (JSON.stringify, util.inspect, json.dumps, str) around the environment, or printenv or env piped to a sender, is a dump; a spread or copy of the environment (env_copies) counts only when it goes into a send (a send call earlier on its line, or a send within 10 lines with no spawn near) and is not the env option or an env-named variable of a child process. in_comment lexes the line (strings, regex literals, block comments); a line starting with a star is a comment only in languages with block comments. exfil rules run on Code files only; dotted indicators are written with [.] in patterns and split with concat! in tests so the repo scans itself clean.
