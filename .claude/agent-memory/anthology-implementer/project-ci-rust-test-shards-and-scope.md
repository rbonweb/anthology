ci/jobs/rust-scope.sh (rules ci/scope-rules.tsv, weights ci/test-weights.tsv, graph ci/jobs/rust-graph.mjs, node plus cargo metadata --no-deps) maps changed files to crates plus every dependent (dev deps count; the closure for atl and fuzz ignores them), the golden surfaces of those crates, atl, atl-macos, fuzz and macOS, and prints linux_matrix and macos_matrix for ci.yml. Pushes, workflow_dispatch, the full-ci label, a [full-ci] anywhere in a commit message (even in prose: it fired on its own PR) and ci/jobs/rust-*, ci.yml, rust-test.sh, toolchain, root Cargo non-version changes run everything. A path no rule places also runs everything; repo-tests/tests/ci_scope.rs checks every tracked path, rule, weight and crate. The golden replay is one test per surface, golden_replay::<surface> (crates/difftest/tests/golden.rs); the rest shards skip them with --skip golden_replay::. Gates rust-test-linux and rust-test-macos stay the required checks (rust-gate.sh JOB SCOPE RUN SHARDS). Trap: cargo test -p X does not build the anthology binary that memory, runtime and dev tests run (testkit run_bin); rust-test-linux.sh and rust-test-macos.sh build anthology-cli first for those crates (needs_binary list, pinned by rust_test_jobs.rs). Trap: the old-tool name check (atl_rename.rs) refuses the legacy trim surface name unless the line says legacy. Cache: ci/jobs/rust-cache.sh binds the anthology-cargo, anthology-rustup-* and anthology-sccache volumes to runner folders that actions/cache restores (save only on push), with ANTHOLOGY_SCCACHE=1 because rust-test.sh turns sccache off in CI. A PR can only restore caches saved on its base branch, so the first run after merge to build seeds them. Measured 2026-11-27 with a warm cache: a Linux shard compiles in 19-30 s and every sampled shard hit; a macOS shard (Swatinem/rust-cache) hit and still took 13 min because it runs repo-tests (shims tests ~100 s each, two binaries). The macOS pool queued 20-45 min while other runs held it, so any PR that needs macOS waits on that pool. Why: a PR round was 17+ min and the shared runner pool queues, so fewer jobs per PR finish sooner.
