crates/anthology-scan/src/tree.rs: DiskTree walks breadth first with sorted names. read() opens only regular-file entries (or a link entry at a settings path that resolved inside the root: tree.is_linked), checks lstat then fstat, and adds up bytes read; past max_bytes every read returns QuotaExceeded and partial() turns true. Git modes passed to open are octal (0o120000 symlink, 0o160000 submodule). In a folder the user named, .git (any case) gives only config, config.worktree and non-sample hooks; a gitdir file is read exactly as git does (prefix "gitdir: ", other spaces kept) and a gitdir outside the root is noted (gitdir_outside) and rated MEDIUM autorun.gitdir-outside. A link whose path is an auto-run or agent name, or under a settings folder (SURFACE_DIRS), is resolved inside the root: a file link is read as the file under the link path, a folder link is walked under the link name (hop cap 4, 64 folders, a link to its own ancestor is unresolved); anything unresolved is HIGH autorun.symlink-escape. Path mode skips node_modules, .claude/worktrees, .venv, venv, .tox, .nox and .direnv; URL mode walks them. O_NOFOLLOW is 0o400000 on x86, riscv64, loongarch64 and 0o100000 on arm and aarch64. src/scan.rs: Hooks is a table of function pointers (REAL = the rule modules); tests swap in stubs. Chain: yara hits mapped (high MEDIUM, medium LOW, low INFO) and raised one level in reached files; Reach::expand follows npm run scripts of any depth (pre and post included), strips project-folder variables, maps a folder to its package main or index file; run_by_command files that were not code get a second pass as code (language of the interpreter) and raise_reached_file (payload and hidden caps) runs for every reached code file; case twins are HIGH files.case-twin; files.not-utf8 is HIGH only for strict JSON and .claude (files::is_strict_json_name), MEDIUM elsewhere; one finding per (rule, path) is kept (highest severity, counts summed). The trigger by shape severity matrix is shape::severity, not scan.rs. Why: later waves rely on these names, the hook seam and the partial behavior.
