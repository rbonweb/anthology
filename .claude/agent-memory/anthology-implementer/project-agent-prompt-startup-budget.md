Bless on Zorin and bring the file back: ANTHOLOGY_BUILD_HOST=zorin scripts/remote-build.sh run sh -c with cargo run --locked --quiet -p anthology-dev -- golden bless --surface dev.startup-budget, then echo a marker line, base64 of the golden file, and an end marker, stdout redirected to a temp file. Strip the two marker lines and decode with base64 -d into the golden path, then gzip -t it. A first run can fail with an rsync mkstemp error when the remote folder was cleaned meanwhile: just rerun.
