A shared line added to the Shell section of all 11 agent prompts pushes some agents over budget and makes ui-designer 61 body lines against the cap of 60 in roster.rs test_body_shape. 2026-11-27 (126 bytes): architect, debugger, docs-writer and scout went over; ui-designer needed two Do lines merged. 2026-11-28 (credential path rule, 393 bytes): architect, debugger and scout went over again; ui-designer was at exactly 60 lines.
Fix without touching anything outside the Shell section (another branch edits ui-designer elsewhere): merge two Shell lines in all 11 agents (Durations come only from timestamps you read, plus A report names a settings key) so the new rule adds no line, then raise only the BUDGET rows that scripts/dev.sh startup-budget reports as OVER, by the added bytes (git cat-file -s old versus wc -c new), with the reason in the row comment. That keeps the old spare bytes (debugger 1, scout 3).
ui-designer sits at exactly 60 body lines (the blank lines between sections count). To add Do lines (design bar, 2026-11-28, 4 new lines) merge boilerplate Do lines instead: Time plus While developing, Commits plus Project map, Bash in a worktree plus One git command, and the two Don't lines. Roster needles for these are plain substring checks on the whole body, so merged lines pass. A new rule gets a needle test in roster.rs (test_design_bar_rules_are_in_the_prompts); run it once against the old prompts to see it red. Measured deltas that run: ui-designer +1204 bytes, ui-reviewer +941, product-planner +248; only ui-reviewer is tight (1109 bytes free of 65986), so another reviewer rule needs a budget decision or dropping web-design-guidelines (pinned in smoke.rs, repo.rs, repo_layout.rs and evals/knowledge-ui-reviewer/case.yaml).
The budget table lives in crates/anthology-dev/src/startup_budget.rs and is pinned verbatim in crates/anthology-dev/tests/startup_budget.rs (the_budget_table_is_gc13_verbatim). Since copy-and-marketing A1, crates/repo-tests/tests/roster.rs has no copy: its budget module wraps anthology_dev::startup_budget. A conditional Startup line (ending in ", only when|for|to ...") adds only the largest of its files, so a new conditional read costs nothing until it is the largest. crates/difftest/src/surfaces/dev_upstream_watch.rs pins its own table; leave it, bless instead. rustfmt drops the column alignment of trailing comments in these tables when a comment is long, so run rustfmt on the files (container, rustup component add rustfmt first) or CI fmt goes red. Roster needles for the Shell wording are in every_agent_has_the_same_shell_section: add one for a new line. Run scripts/dev.sh startup-budget before committing a prompt change, then bless dev.startup-budget (it drifts on any agent byte change) and check dev.upstream-watch (drifts only when the scout budget moves).
Why: headroom per agent is tiny after earlier Shell additions, so any shared wording change needs a budget decision and a line count check.
