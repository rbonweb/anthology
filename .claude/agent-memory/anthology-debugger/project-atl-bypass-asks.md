PR 259 (atl 1.2.1-anthology.9) enforces one principle in the Claude hook: ATL never widens permissions. A line gets no decision of ours (so Bash(atl *) approves it) only when Claude Code would have allowed the original anyway: read-only by anthology perm classify, or covered by the user's own allow rules. Before, with no deny, ask or Read rule the gate was inert; rewrites and typed atl lines (bypass, proxy, run, err, test, summary, atl <tool>, atl init -g and the other writing subcommands) said nothing, and the host allowed any command behind them.

Where: anthology_gate.rs atl_use (typed atl forms and non-literal subcommand words, with or without rules, gated by mentions_token_layer) wired in decision::decide_for_claude_hook_at as Gate::Ask. read_only_proof.rs refine: AllowRewrite and host-judged rewrites are kept only if covered (allowed or proven), otherwise Defer (original untouched); a hook ask is dropped only if covered. user_allow.rs matches the user's allow rules as Claude Code does (exact, prefix:*, trailing space-star makes args optional, wildcard; a rule with a backslash matches nothing; rules that match an atl blanket probe never count for an atl command word). without_atl strips only the bare word atl or rtk at a command start, global flags, runner subcommands (bypass proxy run err test summary) plus their inner word, wrapped-tool names; readers become cat. A path to atl, env, an assignment, quotes all stay and so ask. Newlines and lines over 4096 bytes are never proven.

Why it is built so: the real classifier refuses any atl line, but the test stand-in (FAKE_PROVE_ALL) passes everything, so ATL re-scans the stripped line itself. A path-qualified atl could be any program, so it is never stripped.

Traps: tests named inert_in_a_bare_sandbox now assert an ask or use the proven() helper (a stand-in classifier) for read-only rewrites. fish_wrap_test claude_hook adds an allow Bash(*) unless a test names its own settings file. The hook check diagnostic uses the pre-refine answer and reports an ask about the line as typed as no rewrite. BYPASS_NOTE (crates/anthology-settings/src/ops.rs), the setup SKILL.md copy and the runtime setup test const BYPASS must change together; the setup golden then needs a bless, and the change ships with the next anthology-bin release (not bumped in PR 259). Bumping atl/Cargo.toml, decision.rs or hook_cmd.rs moves the dev.rtk-trim golden: bless under umask 022 with scripts/dev.sh golden bless --surface dev.rtk-trim. Run atl tests with scripts/atl-test.sh --test NAME; rustfmt touched files only through scripts/rust-test.sh run rustfmt --edition 2024 (cargo fmt --all fails on the trimmed tree; hook_cmd.rs only via stdin); the macOS check is a throwaway draft PR whose only change is a comment line in .github/workflows/atl-release.yml, based on the fix branch.
