# Anthology Rust port: implementation plan

- **Design:** [`docs/superpowers/specs/2026-11-20-rust-port-design.md`](../specs/2026-11-20-rust-port-design.md). "D§9" means design §9.
- **Revision 2.** It applies `.superpowers/sdd/RUST/plan-review.md` (C-1, I-1 to I-12, m-1 to m-22) and the controller's rulings on it. §6 maps every finding to its fix. **This plan is authoritative for lane facts.**
- **Who reads what:** an implementer reads **§0**, **§2 (Global Constraints)**, **§3 (shared interfaces)** and **its own task**.
- **Branches.** The integration branch is `rust`, created from `build` after fix-f1 merges. Each lane works in its own worktree on `rust-<lane>`, branched from `rust`. Merges back into `rust` are **serial and done by the controller** (§0.2). The controller merges `build` into `rust` at least weekly.
- **SDD ledger:** `.superpowers/sdd/RUST/`, with the same conventions as `.superpowers/sdd/PLAN/`.

## 0. Protocol

### 0.1 Rules for every lane

1. **No live switch before CO2.**
   - Until cutover, nothing a user or CI already runs changes behaviour: `hooks.json`, `skills/*/SKILL.md`, `bin/*`, `scripts/*.sh`, and workflow steps that run Python.
   - Final versions are written under `port/staging/<same relative path>`, tested there, and moved into place by CO2.
   - Additive repo changes (new crates, jobs, workflows, Dockerfiles) land directly. F1 creates all of them up front (§0.2).
2. **Python source is read-only**, except:
   - the oracle drivers in `port/difftest/oracle/`;
   - the extractors in `port/extract/`;
   - Python meta-test edits that an additive change forces. These are made **only by the controller**, in a plumbing PR (§0.2).
3. **Definition of Done (DoD) for a task:**
   - `scripts/rust-test.sh` is green (`fmt --check`, clippy `-D warnings`, `cargo test --workspace --locked` in the rust image), and so are CI `rust-test-macos` and `shims-distros` where the task touches shims;
   - `cargo deny check` is green;
   - `scripts/difftest.sh --surface <the task's surfaces> --gen 10000` gives **0 unexplained diffs** on Linux, and on macOS for CLI surfaces;
   - `anthology-dev ledger check --files <the task's Python test files>` is green;
   - spec review and code-quality review pass (`stream-protocol.md`, at most 3 fix rounds).
4. **Tests keep the Python method name.** Table rows live in `crates/<crate>/tests/data/<python_module>.jsonl`, tagged `"py": "<python id>"`. A row may be `ported` only if the Rust test drives the **same branch**, through a GC-19 seam where Python patched something.
5. **Commits** end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Lanes do not bump plugin versions; CO2 does.
6. **Sizes** count Rust lines, implementation plus tests: S < 800, M 800–2,000, L 2,000–4,000, XL > 4,000.

### 0.2 Merge discipline (I-5)

1. **F1 pre-declares everything shared.** Lanes then **never edit** these files:

   | Shared item | What F1 puts there |
   |---|---|
   | root `Cargo.toml` `[workspace.dependencies]` | every crate in D§11.2, exact versions |
   | every crate's `Cargo.toml` | all the dependencies that crate will need |
   | `Cargo.lock` | committed |
   | every `lib.rs`, and `anthology-cli/src/{main.rs,cmd/mod.rs}` and `anthology-dev/src/main.rs` | every module file named in any task's **Files**, as an empty `mod` stub; every subcommand registered (§1.3) |
   | `crates/difftest/src/surfaces/mod.rs` | every surface name registered (§1.4) |
   | `fuzz/Cargo.toml` and its lock | every fuzz target as a stub |
   | `ci.yml` | every job, as a no-op placeholder that echoes its name until its lane fills its own script |
   | `.gitignore` | the replay entries |
   | `ci/images/*.Dockerfile` | the new pinned images |

   A job script lives in `ci/jobs/<job>.sh`, so a lane edits its own script, never `ci.yml`.

   If a lane needs a shared change, the controller makes it in a small **plumbing PR** that merges first.
2. **Shared ledgers are split:**
   - `port/ledger/<python_module>.tsv`;
   - `port/difftest/divergences/<surface>.toml`;
   - testkit helpers in `crates/anthology-testkit/src/<lane>.rs`.
3. **Merges are serial.** The controller merges one lane at a time into `rust` (a merge queue). Before its own merge, every other open lane merges the new `rust` in and re-runs its DoD. Only the controller regenerates `Cargo.lock`, with `cargo update -w --offline`.
4. **Python meta-test edits** caused by additive changes are made by the controller in the plumbing PRs. MT1 **merges last** in wave 1, so its Rust ports include them.
5. **Single owners of contested files:**
   - **RL1** owns `port/staging/scripts/release.sh`.
   - **DV2** owns `port/staging/scripts/sync-rtk.sh`.
   - **DV1** owns `anthology-dev vendor set-rtk-upstream`.
   - **DV4** owns the rtk_trim `--lock-guard` allowlist.
   - **BS1** owns every file under `port/staging/plugins/*/{hooks,bin}/`.
   - **CO2** owns every file move out of `port/staging`.

### GC-7 Session start

- **Constants:** `GUARD_TIMEOUT=10`, `RTK_TIMEOUT=8`, `DEADLINE=50`, `RTK_MIN_REMAINING=40`, `CONTEXT_BUDGET=9000`, `MESSAGE_CAP=2000`.
  - The memory section budget is `Budget(40 lines, 2500 bytes)`.
  - `systemMessage` = `msg if len ≤ 2000 else msg[:1999].rstrip() + "…"`.
- **Time budget (I-7):**
  - **`BOOTSTRAP_BUDGET = 20` s** wall per download, including connect.
  - **At most one download per session-start hook process.** `hooks/session-start.sh` runs `bootstrap.sh session --plugin anthology --quiet --budget 20` and exports `ANTHOLOGY_BOOTSTRAP_DOWNLOADED`.
  - Rust ensures the live guard's version only if `ANTHOLOGY_BOOTSTRAP_DOWNLOADED=0` **and** `min(20, DEADLINE − elapsed_T0 − GUARD_TIMEOUT − 5) ≥ 20`. Otherwise it defers to the guardrails SessionStart hook, the shim, or the next session.
  - **All elapsed checks count from `ANTHOLOGY_HOOK_T0`.** A session start that downloaded a binary therefore normally skips the rtk check, with the existing message (F-20).
  - Test: with a downloader that never finishes, the shim prints one JSON line within **45 s**.
- **Stdin** is read only when it is not a TTY; only `cwd` is used.
- **Step labels** (`anthology: %s failed (%s)`): `reading the hook input`, `the guardrails self-test`, `reading state.json`, `recording the plugin data folder`, `the plugin-read permission check`, `the settings version check`, `the rtk check`, `the plugin data folder check`, `the bin wrapper check`, `the agent-memory path check`, `the subagent model check`, `memory sync`, `reading the routing guide`, `assembling the session context`, and the new `ensuring the guardrails binary`.
- **Order:**
  1. Windows → `REFUSAL` only.
  2. Ensure the live guard binary (budget rule above).
  3. The self-test.
  4. State.
  5. NAG, or the read-rule, ops-version and rtk checks.
  6. The data-dir, wrapper, agent-memory and subagent checks.
  7. Memory sync.
  8. The guide.
  9. Compose.
  10. Prune `<ah>/bin`.
- **Composition.** The guide is never cut. The context is the guide + `\n` + memory, with memory cut at the last newline that fits `9000 − len(head)`, plus:
  `` (memory index truncated to fit the session budget; use `anthology-mem search <query>`; full indexes: %s, and .claude/memory/MEMORY.md in the repo) ``
- **Verbatim strings:**
  - `Anthology supports macOS and Linux only; it is inactive on Windows.`
  - `anthology: run /anthology:setup to finish installing (rtk, permissions, memory)`
  - `anthology: Claude Code did not pass CLAUDE_PLUGIN_DATA to the hook; rtk and the memory search index have no data folder (compatibility check)`
  - `anthology: CLAUDE_CODE_SUBAGENT_MODEL is set, so every agent runs on that model and the roster's model tiers do not apply`

### GC-16 Parity rules, regex treatment and allowed divergences

- **JSON** goes through `pycompat::json` only. `serde_json` is absent from `cargo tree -p anthology-cli -e normal`, enforced by a `repo-tests` check (m-11).
- **Authority.** CPython 3.12 in the pinned image gates. 3.9 differences are recorded in a non-gating report (m-7).
- **Strings.** Code points; `pycompat::str` for case (including Final_Sigma), whitespace and digits; `pycompat::re::{W,S,D}`; `\Z` → `\z`.
- **Errno text (I-10).** `PyExc::py_str` uses the committed tables `pycompat/src/errno_tables/{linux_glibc,macos}.rs`, generated by `anthology-dev gen-errno` from the oracle (Linux, 3.12 image) and the macOS runner. It never uses libc `strerror` or `io::Error` `Display`. The difftest compares the full text.
- **Regex treatment (I-8).** `regex` where there is no lookaround or backreference; `fancy-regex` otherwise.

  | Pattern | File:line | Construct | Rust |
  |---|---|---|---|
  | `_HEREDOC_START` | guard_rules.py:92 | `(?!<)`, `\1` | `anthology-shell`, fancy-regex |
  | `_HOME_VAR` | guard_rules.py:914 | `(?!…)` | `anthology-guard`, fancy-regex |
  | `_TILDE_USER` | guard_rules.py:915 | `(?=/\|\Z)` | `anthology-guard`, fancy-regex (`\Z`→`\z`) |
  | jwt | memory_privacy.py:51 | `(?<!…)` | privacy, fancy-regex |
  | `_EMAIL`, `_IPV4`, `_IPV6`, `_PRIVATE_HOST`, `_SSH_COMMAND`, `_USER_AT_HOST`, `_KEY_NAME` | memory_privacy.py:77-87 | look-behind and look-ahead | privacy, fancy-regex |
  | `$HOME` literal, hostname | memory_privacy.py:136, :154 | look-ahead and look-behind, dynamic | privacy, fancy-regex, built at call time |
  | vendor transforms | vendor.py:314, :351, :572 | lookaround | `anthology-dev`, fancy-regex |
  | upstream watch | upstream_watch.py:678 | lookaround | `anthology-dev`, fancy-regex |
  | smoke | smoke.py:219, :366 | lookaround | `anthology-dev`, fancy-regex |
  | portmap `js_node_regex` | vendor/patches/*.portmap.json | none today (checked) | `pycompat::re::translate` → fancy-regex |

- **Backtrack limit.** Use fancy-regex's default limit unless a lane proves a higher one is needed. A limit error is:
  - an **`unscannable` finding** in privacy;
  - a **block** (`(internal)`) in shell and guard (`Analysis.incomplete`);
  - **exit 1** with the pattern name in dev tools.
- **Allowed divergence classes** (`port/difftest/divergences/<surface>.toml`; anything else fails):
  - **D-1 Python raised** (an exception or RecursionError, failing open). Rust may block or match, and must never allow what Python blocked.
  - **D-2 Library error text** after a fixed prefix.
  - **D-3 `\b`** next to a mark, `No` or `Pc` code point.
  - **D-4 argparse usage text** at exit 2.
  - **D-5 Byte encodings with equal content** (gzip, SQLite files).
  - **D-6 Lone surrogates → U+FFFD** (F-19).
  - **D-7 Resource limits:** a regex backtrack limit or the 8 s guard watchdog. Rust may block or report more (`unscannable`), never less.

- **CLI:** `bootstrap.sh <session|guard|wrapper> --plugin <anthology|guardrails> [--quiet] [--budget S]`.
- **Downloaders in order:**
  1. seeded archive;
  2. curl `-fsSL --proto '=https' --proto-redir '=https' --connect-timeout 10 --max-time $B --max-filesize 67108864 -A anthology-bootstrap`;
  3. GNU wget `--https-only -q -T 10 -U anthology-bootstrap`, under the watchdog;
  4. BusyBox wget `-q -T 10`, under the watchdog, with no https-only flag (the pin decides);
  5. `node -e <fixed script>` (https-only, ≤ 5 redirects, 64 MiB cap, own timeout), under the watchdog.
- **Budgets:** `BOOTSTRAP_BUDGET` 20 s (`session`, `guard`, `wrapper`); setup uses 60 s.
- **Rate limit.** 60 s via `<ah>/bin/.attempt`, created under noclobber (`set -C`). `session` mode never reads or writes it.
- **Integrity markers:**
  - "installed" = real directory + regular executable + non-empty `.sha256`;
  - "current" = installed + `.sha256` == the lock hash + `.bin-sha256` == the sha256 of the binary.
- **Quarantine.** On any guard exit other than 0 or 2, or a `.bin-sha256` mismatch, rename to `.broken-<version>-<epoch>`. Three strikes per version in 24 h stops reinstalls.
- **Read-only allowlist:** `Read Grep Glob LS NotebookRead WebFetch WebSearch TodoWrite TaskCreate TaskUpdate TaskGet TaskList TaskOutput TaskStop Task Agent Skill ToolSearch AskUserQuestion EnterPlanMode ExitPlanMode BashOutput KillShell`.
- **Prune:** 30 days unused; `.tmp-*` and `.broken-*` older than 24 h.

### GC-18 Engineering rules

- **Toolchain** `1.100.0`, edition 2024. Only the **channel** must equal rtk's (m-17).
- **`#![forbid(unsafe_code)]`** everywhere except `anthology-core::sys`.
- **`--locked`** builds; no host Rust (`scripts/{rust-test,dev,difftest}.sh`).
- **Guard hot path:** no network, no SQLite, no file reads beyond stdin. `HOME` is resolved by the CLI, with the passwd lookup allowed (m-19).
- **Runtime crates take `&Env` and a `Deps` (GC-19)**, and never read `std::env`.
- **No `println!` in libraries.** Commands return `Output { stdout, stderr, code }`.
- **`anthology-shell`'s `Cargo.toml` is self-contained** (no workspace inheritance; m-15).
